CSS سفارشی

کلاس‌های اورلی چت: .msg (یک پیام)، .msg .user (نام)، .msg .badge (بج؛ نوع‌ها: broadcaster moderator vip subscriber founder og verified staff sub_gifter)، .msg .badge-img (بج تصویری)، .msg .emote (ایموت)، #pinned (باکس پین)، #chatStatus (خط وضعیت).

کلاس‌های Goal: #goal .title، #goal .values، #goal .bar، #goal .fill، #goalError.

متغیرها: --chat-font-size، --chat-bg-opacity، --chat-text، --chat-radius، --chat-gap، --goal-title-size، --goal-bar-h، --goal-c1، --goal-c2. مثال: .msg { border: 2px solid #f00; }

پیش‌نمایش زنده

راهنمای Meld Studio

پس‌زمینه‌ی اورلی‌ها کاملاً شفاف است؛ نیازی به Chroma Key نیست. مصرف هم سبک است: چت فقط با رویداد زنده می‌آید و سقف پیام دارد، و Goal هر ۱۰ ثانیه یک‌بار خوانده می‌شود.

  1. ReChat را اجرا کن؛ در بخش چت نام کانال را بزن و «اتصال» را بزن تا وضعیت «متصل ✓» شود.
  2. لینک Goal را در بخش Goal بزن و «ذخیره» را بزن تا وضعیت Goal هم «متصل ✓» شود.
  3. در Meld، در پنل Layers روی + بزن و Browser را انتخاب کن — یا لینک را مستقیم روی بوم با Ctrl+V بچسبان تا لایه‌ی Browser خودش ساخته شود.
  4. لینک اورلی را از ReChat کپی کن (بخش لینک‌های اورلی، یا لینک همان پروفایل) و در قسمت URL پنل Inspector بچسبان.
  5. اندازه را روی بوم با کشیدن گوشه‌ها تنظیم کن، یا W و H را در Inspector بنویس (پیشنهاد: چت ۴۲۰×۷۰۰، Goal ۹۰۰×۱۸۰). برای ثابت ماندن اندازه‌ی صفحه هنگام تغییر لایه، Lock Size را فعال کن.
  6. اگر پیام تازه نیامد، روی آیکن تازه‌سازی (reload) کنار فیلد URL بزن.
  7. برای هر صحنه، پروفایل همان صحنه را در ReChat انتخاب کن و لینک همان پروفایل را در Meld بگذار.
  8. ReChat باید در تمام مدت استریم باز بماند؛ لینک‌ها فقط روی همین سیستم (localhost) کار می‌کنند و بدون ReChat چیزی نشان نمی‌دهند.

اگر صفحه سیاه دیدی: اول مطمئن شو لایه‌ی دیگری روی آن نیست، بعد reload را بزن. اورلی‌های ReChat صدا ندارند، پس نیازی به «Add an audio track» نیست.

درباره‌ی ReChat

نسخه‌ی ۰٫۱٫۰ (M1 — اسکلت). چت و Goal کیک را می‌گیرد و به‌صورت اورلی شفاف به Meld می‌دهد. بدون لاگین؛ تنظیمات فقط روی همین سیستم می‌ماند.
